# 인터뷰 결과 (루프 자동 진행용 기본값)

사용자 인터뷰를 생략하고 아래 기본값으로 확정했다. 모두 가정이며 시험용 MVP다.

- 사용자: 개인 한 명 (계정 없음)
- 해결하는 문제: 떠오른 생각을 빠르게 적어 두고 다시 본다
- 핵심 흐름: 메모를 입력해 추가하고, 목록에서 확인한다. 새로고침이나 재시작 후에도 메모가 유지된다
- 스택 제약: 이 머신에 설치된 도구로 가장 단순하게. 확인된 도구는 node, npm, python3, uv (bun 없음). 새 도구 설치 금지
- 제외: 로그인, 검색, 수정, 삭제, 배포, 태그
- 저장: 설정이 필요 없는 방식 (파일 또는 SQLite)
